## Uzun açıklama

```
Pure Performance, Windows kararlılığını ve önyükleme davranışını anlamanıza yardımcı olur—korku pazarlaması veya sahte “çöp skoru” olmadan.

CRASH ANALYZER (ÜCRETSİZ)
Application ve System Event Viewer günlüklerinde kernel-power olayları, uygulama kilitlenmeleri, disk hataları ve BSOD’ları tarayın. Sade Türkçe/İngilizce açıklamalar alın. Bulgular tamamen kopyalanabilir; destek kayıtlarına veya notlara yapıştırabilirsiniz. Tarama sırasında hiçbir şey silinmez.

STARTUP MANAGER (ÜCRETSİZ)
Registry Run anahtarlarını (HKCU / HKLM) ve Başlangıç klasörü kısayollarını inceleyin. Devre dışı bırakma, girdiyi Pure Performance yedek alanına taşır; böylece yeniden etkinleştirebilirsiniz—değerler kalıcı olarak silinmez. Tüm kullanıcılar için değişiklikler yalnızca gerektiğinde UAC ister.

AYRICA ÜCRETSİZ
• Canlı performans panosu — CPU, bellek, disk ve GPU (mümkün olduğunca) ile yüksek kullanımlı işlemler
• Sistem Temizleyici — yalnızca adı verilen geçici ve önbellek klasörleri
• Bellek Optimizasyonu — erişilebilir işlemlerde EmptyWorkingSet
• Açık / Koyu / Sistemi izle temaları ve ücretsiz vurgu renk paketleri

İSTEĞE BAĞLI PURE PERFORMANCE PRO
Dayanıklı (durable) bir Microsoft Store eklentisi, istediğinizde üretkenlik araçlarını açar:
• Yerel Markdown özet raporlarıyla zamanlanmış taramalar

• Otomatik optimizasyon kuralları
• Çoklu PC profilleri (yerel; bulut senkron iskeleti)
• Gerçek zamanlı CPU/disk uyarıları
• Temizleyici / Başlangıç beyaz listesi
• Kendi AI yardımcınız (API anahtarınız Windows PasswordVault’ta saklanır)

BU UYGULAMA NE DEĞİLDİR
• Kayıt defteri temizleyici değildir

Temel araçlar ücretsiz kalır. Pro isteğe bağlıdır. Yalnızca ihtiyaç duyulan işlemler için UAC ile yükseltme yapılır.
```

## Özellik maddeleri

1. Ücretsiz Crash Analyzer — kopyalanabilir, anlaşılır Event Log bulguları  
2. Ücretsiz Startup Manager — yedekle geri alınabilir devre dışı bırakma  
3. Canlı Pano — CPU, RAM, disk, GPU ve üst işlemler  
4. Dürüst Sistem Temizleyici — yalnızca adlandırılmış klasörler; kayıt defteri temizliği yok  
5. Ücretsiz temalar ve vurgular — Açık / Koyu / Sistem + renk paketleri  
6. İsteğe bağlı Pro — zamanlanmış raporlar, gelişmiş çökme araçları, kurallar, uyarılar, AI
