## Long description

```
Pure Performance helps you understand Windows stability and boot behavior—without scareware or fake “junk scores.”

CRASH ANALYZER (FREE)
Scan Application and System Event Viewer logs for kernel-power events, app hangs, disk errors, and BSODs. Get plain-English explanations. Every finding is fully copyable so you can paste into support tickets or notes. Nothing is deleted during a scan.

STARTUP MANAGER (FREE)
Review Registry Run keys (HKCU / HKLM) and Startup-folder shortcuts. Disable moves an entry to a Pure Performance backup so you can re-enable it—values are not permanently deleted. All-users changes may prompt for UAC only when needed.

ALSO FREE
• Live performance dashboard — CPU, memory, disk, and GPU (best effort) plus high-usage processes
• System Cleaner — named temp and cache folders only
• Memory Optimizer — EmptyWorkingSet on accessible processes
• Light / Dark / Follow system themes and free accent color packs

OPTIONAL PURE PERFORMANCE PRO
A durable Microsoft Store add-on unlocks productivity tools when you want them:
• Scheduled scans with local Markdown summary reports
• Advanced Crash Analyzer (trends, correlations, export)
• Auto optimization rules
• Multi-PC profiles (local; cloud sync scaffold)
• Real-time CPU/disk alerts
• Cleaner / Startup whitelist
• Bring-your-own AI assist (your API key, stored in Windows PasswordVault)

WHAT THIS APP IS NOT
• Not a registry cleaner
• Not a “boost your PC 200%” product
• No deceptive junk-score cleanup claims
• Cleanup always names exact folders

Core tools stay free. Pro is optional. Elevate with UAC only for actions that need it.
```
