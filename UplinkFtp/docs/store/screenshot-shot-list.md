# Store screenshot shot list

Capture on a **real Windows** build (Store or unpackaged). Placeholders under `packaging/store-assets/screenshot-templates/` are layout guides only — **do not submit placeholders** to Partner Center.

## Required sizes (desktop)

| Size | Role |
| --- | --- |
| **1366 × 768** | Minimum desktop screenshot (at least 1) |
| **1920 × 1080** | Preferred promo / Store detail |

Also keep 9:16 phone sizes **optional** (desktop-only app).

## Shots to capture (5–8)

1. **Hero — dual pane** — Connected session, local + remote browsers populated.  
2. **Quick connect / brand** — Top connect bar with Uplink branding visible.  
3. **Transfer queue** — Active or completed/failed row visible.  
4. **Site Manager** — Saved sites list (no real passwords on screen).  
5. **Settings → Theme** — Sun Rise or another theme selected; readable UI.  
6. **License** — Free tier status; Buy Pro visible on Store channel (optional).  
7. **AI Assist** (optional) — Troubleshoot or Quick Edit tab with sample text (no API keys).  

## Capture tips

- Use a clean demo host / local FTP docker; scrub hostnames if needed.  
- Prefer **Sun Rise** or a high-contrast theme for listing clarity.  
- No stub license keys, secrets, or customer data in frames.  
- Export PNG; sRGB; no heavy compression artifacts.
