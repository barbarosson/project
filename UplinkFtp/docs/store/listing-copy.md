### Title
Uplink FTP

### Short description (≤200 characters recommended)
Modern Windows FTP, FTPS, and SFTP client with dual-pane transfers, site manager, and a free tier—unlock Pro in the Microsoft Store.

### Full description

Uplink FTP is a desktop FTP / FTPS / SFTP client for Windows. Connect quickly, browse local and remote folders side by side, queue transfers, and manage saved sites—with a clear Free tier and an optional Pro unlock.

**Highlights**
- Dual-pane local and remote browsers  
- FTP, FTPS, and SFTP in one shell  
- Transfer queue with pause / resume / retry  
- Site Manager with OS-protected credentials  
- Free tier for everyday use; Pro unlocks higher limits  
- Optional AI Assist (bring your own API key)  

**Free vs Pro**
- Free: up to 3 saved sites, 1 concurrent connection, 1 concurrent transfer  
- Pro: unlimited sites, connections, and transfers (via durable Store add-on **Uplink FTP Pro**, or a Web license key on sideload builds)

Telemetry is **off by default**. Passwords are not stored in the site database.
