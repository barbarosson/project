## Before contacting support

1. Note app version from About / `CHANGELOG.md`  
2. Confirm Free vs Pro and distribution channel (Store vs Web)  
3. Attach sanitized logs (**no passwords**, **no API keys**)  
4. Check `docs/known-issues.md`
